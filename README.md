# Echo / 影子跟读

面向个人练习的网页应用。选定的方案 1 已实现为可操作界面，不是静态设计图。

## 使用

1. 打开本地预览 `http://127.0.0.1:4173/`。
2. 可以直接使用内置的 8 句合成英语音频，或点击 **导入素材**，选择视频／音频与 SRT／VTT 字幕。
3. 选择一句，点击 **开始跟读**，在浏览器提示时允许麦克风。
4. 默认先听原声，再自动录音；录音后按设置重复。随时点击主按钮结束或停止。
5. 在 **本句练习记录** 回放每次录音，点击 **原声 → 我的录音** 交替对比。
6. 书签按钮把句子加入 **复习**。录音可以单独下载，复习页可以导出不含音频的 JSON 记录。

示例为 Microsoft Zira 生成的合成音频，配 AI 生成的静态封面，**不是真人访谈视频**。英文文案和中文译文为本项目示例内容。示例字幕提供在 `public/demo.srt`。

### 练习设置

- 0.6／0.8／1.0／1.2 倍速；重复 1／2／3／5 遍；自动进入下一句。
- **连续练习**：在练习设置开启“自动进入下一句”，从当前句连续练到素材结尾。内置音频为短示例，可导入更长的视频 / 音频和配套字幕。
- **先听后读**：播放完一句，再录音，留出该句时长加 1.2 秒；最长 5 分钟；练习设置可选至少 30 秒、1 分钟、2 分钟或 5 分钟，随时结束会保存录音。
- **同步跟读**：边播放边录音，到句尾停止；建议戴耳机，减少原声进入麦克风。
- 眼睛图标隐藏播放器和句子列表中的字幕；滑杆图标可修改本句文本、译文和时间。
- 修改文本后，历史录音与评分仍绑定录音时的文本，避免把旧分数用于新句子。

### 导入要求与数据保存

支持浏览器可解码的 MP4、WebM、MP3、WAV、M4A 等文件，不设文件大小上限，实际保存受浏览器可用空间和设备资源影响；MP4 建议使用 H.264/AAC。SRT／VTT 必须包含时间轴，句子不能重叠；超出素材时长的字幕仍完整保留并提示，播放只使用已有原声，不设字幕条数、单条文本长度或总时长上限，长字幕按每页 100 句显示，支持跳转到指定句。实际可加载规模受浏览器内存和本地存储空间影响。双语字幕按英文练习文本和中文译文处理。纯文本自动对齐与视频网站 URL 导入暂未实现。

素材、录音、书签保存于当前浏览器的 IndexedDB；偏好与练习位置保存于 localStorage。更换浏览器、清除网站数据或浏览器回收存储可能使记录丢失；重要录音请下载。没有账号同步。导入文件默认不上传服务器。

## 开发与启动

需要 Node.js **22.18+ 或 24+** 与 npm。当前开发环境的 Node.js 为 23.9。

```powershell
npm ci --cache .npm-cache --registry https://registry.npmjs.org
npm run dev
```

也可在安装依赖后双击 `start.cmd`。开发地址固定为 `http://127.0.0.1:4173/`；已经启动的预览无需重复启动。

```powershell
npm run typecheck
npm test
npm run build
npm start
```

生产构建在 `dist/client`，`npm start` 使用项目自带 Node 服务提供静态文件和评测 API。`PORT` 默认 4173，`HOST` 默认 127.0.0.1。录音需要 HTTPS 或 localhost；部署到远程服务器时配置 HTTPS 反向代理。

Bundled Product Design 的 Sites 静态 Worker 保留于 `dist/server`；它只负责静态托管，不包含本项目的 Node 语音代理。需要云评测时使用 Node 服务，或另行提供受保护的同源 API。

## 开启真实发音评测

不配置服务也能完成播放、录音、对比与复习。**没有服务结果时，应用不会制造分数。**

1. 在 Azure 创建 Speech 资源。
2. 将 `.env.example` 复制为 `.env`，在本机编辑密钥与区域：

```dotenv
AZURE_SPEECH_KEY=your-resource-key
AZURE_SPEECH_REGION=eastasia
AZURE_ENABLE_PROSODY=false
```

3. 重启开发或生产服务，在页面“练习与评测设置”中检查连接状态。
4. 完成录音后点击“评测此录音”。此操作才会发送该录音和录音时的参考文本到 Azure Speech，可能产生服务费用。

评测固定为美式英语 en-US。服务端校验 16kHz 单声道 PCM WAV、0.3–30 秒录音，并代理官方短音频接口。页面展示准确度、流利度、完整度，以及服务返回时的韵律评分；韵律未返回就显示缺失，不补造数值。韵律是可选服务能力，启用前确认自己的服务能力与费用。

逐词及音素结果帮助定位下一遍应优先练什么；建议从结果中的低分词或漏读词重听、慢读，再放回整句。它评估参考文本下的朗读，**不代表与视频人物的声音相似度**；录音时长和音量也不代表口语水平。

密钥只供后端使用，不使用 `VITE_` 前缀，也不提交 `.env`。首版为个人版，尚未实现用户鉴权、按用户配额和多人数据隔离；对外开放付费语音 API 前需加访问保护。

官方说明：

- [Azure 短音频 REST 与发音评测](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-speech-to-text-short)
- [Azure 发音评测能力](https://learn.microsoft.com/en-us/azure/cognitive-services/speech-service/how-to-pronunciation-assessment)
- [浏览器麦克风安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

## 验证范围

- 自动测试覆盖字幕、示例时间轴一致性、WAV 编码、服务端音频校验、评分解析、鉴权失败提示、未配置与跨站请求。
- 浏览器验证包含逐句播放、速度／循环切换、素材导入、刷新恢复、书签复习、字幕编辑、桌面／手机布局。
- `tests/browser-runner.html` 是仅用于开发的集成测试入口，使用合成音频流验证真实 AudioWorklet、重采样、WAV 编码、自动练习与 IndexedDB；不申请麦克风、不调用云服务，不进入生产构建。诊断录音可由测试页清理。
- 合成信号测试不能替代真实设备的权限、麦克风采集、耳机串音和人工发音体验测试。
- 当前未使用真实 Azure 凭据进行收费服务联调；接口请求与响应映射已通过模拟服务测试。
- 视觉与交互证据在 `qa/`，结论在 `design-qa.md`。

## 源码

- `src/App.tsx`：练习、导入、录音记录、复习与反馈界面。
- `src/usePractice.ts`：播放 → 录音 → 保存 → 重复／下一句状态衔接。
- `src/audio.ts`、`public/capture-worklet.js`：麦克风采集、音量检测、16kHz WAV。
- `src/subtitles.ts`、`src/storage.ts`：字幕校验与本地持久化。
- `server/assessment.mjs`：语音评测代理和真实结果规范化。
- `server/start.mjs`：生产静态文件与 API 服务。
- `PRODUCT.md`：产品范围、反馈原则与后续迭代。

素材下载：在“导入素材 → 我的素材”中下载原音视频、新导入的原 SRT/VTT，以及导出包含当前时间轴与译文的 SRT。此前导入未保存原字幕的素材，可导出当前字幕。文件留在浏览器本地。

素材删除：在“我的素材”移入回收站，相关录音、评测与复习标记暂时隐藏且可恢复。回收站仍占空间；确认永久删除后，在同一数据库事务中移除素材及关联数据。内置示例不提供删除。

多句练习：在当前句下方的“练习范围”选择 2/3/5/10 句一起练。从选中句到组内最后一句连续播放，保留句间停顿；先听后读或同步跟读、重复次数、自动下一组均适用于整组。句组录音使用合并后的参考文本，与单句录音分别显示；评测仍受 30 秒及 2,000 字符限制。

声波对比：默认自动显示选中录音的波形；点击“对比原声”后才静音流式采样所选原声片段，与选中的录音对比，显示同一时间、振幅刻度下的 RMS 波形；新录音保存当时的字幕范围和语速。波形用于观察时长、停顿及振幅，不代表发音得分，也没有做逐词对齐。采样时间接近所选片段的播放时长，可取消；原声不再整文件读入和解码，工作线程只返回固定数量波形区间的能量。浏览器无法播放音轨时仍可回听录音。
